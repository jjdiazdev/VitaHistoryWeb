# VitaHistory
Version: 1.0
### Project Description:

This project involves the development of a Customer Relationship Management (CRM) system specialized for healthcare professionals, built with the Flask framework in Python. The main objective is to provide specialists with an intuitive and efficient tool to maintain detailed patient records and manage medical histories.

### Key Features:

#### Patient Management:
- Complete registration of patient personal data.
- History of consultations and visits.

#### Detailed Medical Records:
- Recording of physical examinations performed.
- Documentation of accurate diagnoses.
- Tracking of prescribed treatments.
- Monitoring of patient progress over time.

## Intuitive Interface:
Responsive and user-friendly design, accessible from different devices.

## Technologies Used:

- Flask (Python): Web framework for application development.
- Database: Upgraded to MySQL to enhance data security, efficiently manage concurrent records, and improve application scalability.
- HTML and CSS: For the user interface.

**This project was developed as a practice exercise for web application development with Python and is still in development with ongoing improvements.**
